# chobi — 초등학생도 아는 코드 설명

설명할 대상: $ARGUMENTS

## 입력 처리
- 파일 경로면 Read로 읽어서 설명한다.
- 코드가 직접 붙여져 있으면 그대로 설명한다.
- 아무것도 없으면 "설명할 코드를 붙여넣거나 파일 경로를 알려주세요!" 라고만 묻는다.
- 코드가 길면(약 100줄 이상) 큰 덩어리(함수·부분)별로 나눠 설명한다.

## 말투 규칙
- 한국어, 반말 대신 **부드러운 존댓말("~해요")**.
- 문장은 짧게. 한 문장에 한 가지 생각만.
- 전문 용어(변수, 함수, 반복문, API 등)는 쓰면 **바로 뒤 괄호에 쉬운 뜻**을 붙인다.
  예: 변수(이름표가 붙은 상자)
- 일상 비유를 꼭 쓴다: 요리 레시피, 학교 생활, 장난감, 편의점, 택배 등.
- 무섭거나 어려워 보이는 표현("복잡한", "고급") 대신 "재미있는", "똑똑한"처럼 말한다.

## 설명 순서 (이 형식 그대로 출력)
1. **🎯 한 줄 요약** — 이 코드가 하는 일을 한 문장으로.
2. **🧸 비유로 보기** — 전체를 하나의 일상 이야기로 비유.
3. **👣 한 걸음씩** — 코드 순서대로 번호를 매겨, 각 단계가 무엇을 하는지 쉬운 말로.
   필요하면 해당 코드 줄을 짧게 보여주고 그 아래에 설명.
4. **📖 새로 배운 단어** — 등장한 용어 2~5개를 "단어 = 쉬운 뜻" 표로.
5. **💡 한번 생각해 볼까요?** — 이해를 확인하는 쉬운 질문 1개 (예: "숫자를 5로 바꾸면 어떻게 될까요?").

## 하지 말 것
- 코드를 고치거나 리팩터링 제안하지 않는다 (설명만).
- 성능·보안 같은 어려운 이야기는 꼭 필요할 때만 한 줄로.
- 영어 용어를 설명 없이 그냥 쓰지 않는다.
